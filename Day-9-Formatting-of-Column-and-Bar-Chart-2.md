# Day 9: Formatting of Column and Bar Chart - 2

##  Objective
Learn advanced formatting techniques for Column and Bar Charts.

##  Topics Learned
- Format data labels
- Customize legends
- Configure gridlines
- Format X and Y axes
- Use tooltips
- Improve chart spacing and layout

##  Practice
- Applied data labels and legends.
- Customized axes and gridlines.
- Added tooltips and adjusted chart spacing.

##  Key Takeaways
- Good formatting improves chart readability.
- Tooltips provide additional information.
- Proper spacing and layout create professional reports.
