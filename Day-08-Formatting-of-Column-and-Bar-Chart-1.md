# Day 8: Formatting of Column and Bar Chart

##  Objective
Learn how to format Column and Bar Charts to make reports more attractive and easy to understand.

##  Topics Learned
- Change chart colors
- Add borders and background
- Format chart titles
- Customize data labels
- Change font size and style
- Display data values on bars

##  Practice
- Formatted Column and Bar Charts.
- Added data labels and customized colors.
- Improved chart readability using formatting options.

##  Key Takeaways
- Formatting makes charts more professional.
- Data labels help users understand values quickly.
- Proper colors and fonts improve report readability.
