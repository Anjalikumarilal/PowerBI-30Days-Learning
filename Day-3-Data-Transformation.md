#  Day 3: Data Transformation

##  Objective
Learn how to clean and prepare data before creating reports.

##  Topics Learned
- Introduction to Power Query
- Remove unnecessary rows and columns
- Remove blank data
- Rename columns
- Change data types (Text, Number, Date)
- Prepare clean data for reporting

##  Practice
- Cleaned a sample dataset using Power Query.
- Removed unwanted rows and columns.
- Renamed columns and updated data types.

##  Key Takeaways
- Data transformation improves data quality.
- Power Query is used to clean and prepare data.
- Clean data leads to accurate reports and dashboards.
