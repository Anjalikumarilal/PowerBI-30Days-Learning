# Day 4: Append Data

##  Objective
Learn how to combine multiple tables with the same columns using the Append feature in Power Query.

##  Topics Learned
- What is Append Data?
- When to use Append
- Combine two or more tables into one
- Use Append Queries in Power Query
- Example: Merge January and February sales data

##  Practice
- Combined two sales tables using Append.
- Verified the merged data in Power Query.

##  Key Takeaways
- Append combines rows from tables with the same structure.
- It is useful for merging monthly or yearly data.
- Power Query makes data combination simple and efficient.
