# Day 6: Page Formatting

##  Objective
Learn how to format report pages to make dashboards clean and visually appealing.

##  Topics Learned
- Format report pages
- Change page background
- Add and format titles
- Apply themes and colors
- Align and resize visuals
- Improve dashboard layout

##  Practice
- Customized the report page.
- Added titles and changed the background.
- Applied a theme and arranged visuals neatly.

##  Key Takeaways
- Good formatting makes reports easier to understand.
- Consistent colors and alignment improve readability.
- A well-designed dashboard provides a better user experience.
