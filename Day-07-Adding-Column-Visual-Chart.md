# Day 7: Adding Visuals - Column Chart

##  Objective
Learn how to create and customize Column Charts in Power BI.

##  Topics Learned
- What is a Column Chart?
- Add a Column Chart to a report
- Assign fields to Axis and Values
- Customize chart title, colors, and labels
- Understand when to use a Column Chart

##  Practice
- Created a Column Chart using sample data.
- Added Axis and Values.
- Customized the chart for better readability.

##  Key Takeaways
- Column Charts are used to compare values across categories.
- Proper labels and formatting make charts easier to understand.
- Column Charts help identify trends and comparisons quickly.
