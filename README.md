# 📊 30 Days of Power BI Learning Journey

Welcome to my **30 Days of Power BI Learning Journey**!

This repository documents my daily learning, hands-on practice, notes, and mini exercises while learning Microsoft Power BI. My goal is to build strong data visualization and business intelligence skills through consistent practice.

##  Goals

- Learn Power BI from beginner to advanced level
- Build interactive dashboards and reports
- Understand data transformation using Power Query
- Learn DAX functions and data modeling
- Complete hands-on practice every day
- Create real-world Power BI projects
- Build a portfolio for internships and placements

##  Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Microsoft Excel
- CSV Datasets
