# Day 5: Modeling - Create Relationship

##  Objective
Learn how to connect multiple tables using relationships in Power BI.

##  Topics Learned
- Primary Key and Foreign Key
- Create relationships between tables
- One-to-Many relationship
- Many-to-One relationship
- Example: Connect Product table with Sales table

##  Practice
- Created relationships between two tables.
- Linked Product and Sales tables using a common key.

##  Key Takeaways
- Relationships connect data across tables.
- Primary and Foreign Keys are used to build relationships.
- Proper modeling improves report accuracy.
