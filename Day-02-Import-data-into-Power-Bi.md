## Day 2: Import Data into Power BI

## Objective
Learn how to import data into Power BI, explore the interface, and perform basic data management operations.

=> What I Learned

## Importing Data into Power BI
Power BI allows users to connect and import data from various sources. In this session, I learned how to import data from:
 Excel Workbook (.xlsx)
 CSV File (.csv)
Imported data can be used to create reports, dashboards, and visualizations.

## Viewing Imported Data
After importing the dataset, I learned how to:
      Verify whether the data is loaded correctly.
      Check the number of rows and columns.
      Review column names and data types.
This helps ensure the dataset is ready for analysis.

## Refresh Data
The Refresh option updates the dataset whenever changes are made to the original Excel or CSV file.

Why it is useful: 
            Keeps reports updated with the latest information.
            Eliminates the need to import the same file repeatedly.
## Edit Data
Power BI provides the Transform Data option, which opens Power Query Editor.
In Power Query, data can be prepared before visualization by:
Removing unnecessary columns
Renaming columns
Changing data types
Cleaning missing values

## Understanding the Power BI Interface
I explored the main sections of Power BI Desktop:
Interface	Purpose
 Home Ribbon	Import data, refresh, transform, publish
 Report View	Create charts and dashboards
 Data View	View imported tables
 Model View	Manage relationships between tables
 Fields Pane	Display available tables and columns
 Visualizations Pane	Add charts, tables, cards, slicers, and other visuals

# Questions
Q1. Which file formats can Power BI import?
Answer: Excel, CSV, SQL Server, SharePoint, Web, Azure, and many other data sources.

Q2. What is the purpose of the Refresh option?
Answer: It updates the dataset with the latest changes from the original data source.

Q3. What is Power Query Editor used for?
Answer: It is used to clean, transform, and prepare data before creating reports.

Q4. What are the three main views in Power BI Desktop?
Answer:
      Report View, Data View, Model View
    
Q5. Why is checking imported data important?
Answer: To verify that the data is complete, accurate, and ready for analysis.
